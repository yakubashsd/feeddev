# Telegram бот для отслеживания цен застройщиков

Бот проверяет страницы застройщиков, извлекает цену, сохраняет последнее значение и отправляет уведомление в Telegram, если цена изменилась.

## Быстрый запуск

1. Создайте бота через `@BotFather` и получите токен.
2. Скопируйте пример настроек:

```bash
cp .env.example .env
cp builders.example.json builders.json
```

3. Заполните `TELEGRAM_BOT_TOKEN` в `.env`.
4. Настройте сайты в `builders.json`.
5. Запустите:

```bash
set -a
source .env
set +a
python3 price_bot.py
```

После запуска напишите боту `/start`, затем `/check`.

На macOS может понадобиться строка `SSL_CERT_FILE=/etc/ssl/cert.pem` в `.env`, чтобы Python корректно проверял HTTPS-сертификаты.

## Настройка сайтов

Каждый сайт описывается в `builders.json`:

```json
{
  "id": "builder_name",
  "name": "Название застройщика",
  "url": "https://site.ru/flats",
  "price_regex": "от\\s*([\\d\\s.,]+)\\s*(?:₽|руб|млн)",
  "min_price": 1000000,
  "max_price": 50000000,
  "change_threshold_percent": 0
}
```

Главное поле - `price_regex`. Первая группа в регулярном выражении должна находить число цены. Если рядом найдено `млн`, бот сам переведёт значение в рубли.

Если `price_regex` не задан, бот попробует сам найти цены вида `4 500 000 ₽`, `4 500 000 руб` или `от 4.5 млн`.

## Команды в Telegram

- `/start` - подписать текущий чат на уведомления.
- `/check` - проверить все сайты сейчас.
- `/list` - показать последние сохранённые цены.
- `/chatid` - показать ID текущего чата.

## Важные ограничения

Бот читает HTML страницы. Если цена появляется только после сложного JavaScript-рендера, лучше использовать страницу/API, где цена уже есть в исходном HTML, либо добавить отдельный парсер под конкретный сайт.
