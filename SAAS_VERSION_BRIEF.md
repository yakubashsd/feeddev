# FeedDev SaaS version

Отдельная рабочая версия сервиса для продажи внешним пользователям.

База: текущий рабочий генератор фидов.

Ветка: `codex/saas-admin`

Модель монетизации:

- 1 проект = 5000 рублей в месяц
- тарификация считается по активным проектам клиента

Что нужно развивать в этой версии:

- админка владельца сервиса
- список клиентов и их проектов
- аналитика по выручке
- статусы оплат и активных проектов
- пользовательский кабинет клиента
- роли: владелец сервиса, менеджер, клиент
- ограничение доступа клиента только к своим проектам
- сохранение текущей логики генерации, проверки, мониторинга и синхронизации фидов

Текущая production-версия на `feeds.sozdateli.ru` не должна ломаться при разработке SaaS-версии.
