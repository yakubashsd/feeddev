Мониторинг фидов

Сохраняйте рабочие ссылки и проверяйте, открываются ли они без ошибок. После подключения сервера здесь появятся проверки по расписанию и уведомления.
Telegram-уведомления включаются отдельно у каждого фида. Если заданы TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID, сервис отправит сообщение при новой ошибке проверки. Проверки по расписанию подключаются следующим шагом через серверный мониторинг.

Планировки

Выберите проект, загрузите планировки в библиотеку и наложите их на заранее подготовленную подложку проекта.
Фильтр задает контекст для библиотеки, списка планировок из фида и подложки. Для каждого проекта можно использовать свой готовый макет.
