# Фиды 2.0

Отдельный прототип SaaS-сервиса для внешних пользователей: генерация, кастомизация, мониторинг и публикация XML-фидов для агрегаторов недвижимости.

## Что внутри

- Рабочая область для загрузки и настройки фида.
- Раздел фидов и мониторинга.
- Раздел планировок и брендирования.
- Подписочная модель с тарифами.
- Админка для клиентов, подписок, лимитов и системных событий.

## Запуск

Откройте `index.html` в браузере.

Для локального сервера:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.
